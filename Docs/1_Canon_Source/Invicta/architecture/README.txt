Luxuria Invicta - empty-shell geometry data package
Axes: x km from prow tip (0) to stern (34.0); y km across beam, port negative; z m above keel (side profile in km).
Files: hull_plan_km.csv (plan silhouette), hull_side_profile_km.csv (centerline section), deckN_<city>_gross_km.csv and _net_km.csv (slab outline and city-floor outline, mirrored about y=0 already listed in full), frames_F0_F68.csv (widths at each 500 m frame), zone_reservations_km.csv (reserved zones, flat and empty in the shell).
